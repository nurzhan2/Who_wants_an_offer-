# Промты для Claude Code

Каждый файл содержит один или несколько промтов фазы. Промт вставляется в
Claude Code **целиком**, без правок, в чистой сессии, из корня репозитория.

## Как запускать

```bash
cd Who_wants_an_offer-
git checkout -b feat/phase-XX-name
claude
# вставить блок промта
```

## Правила

1. **Одна фаза — одна сессия.** Не мешай фазы в одном контексте.
2. **Сначала план.** Каждый промт начинается с требования показать план и
   дождаться подтверждения. Не пропускай этот шаг — дешевле поправить план,
   чем 40 файлов.
3. **Ревью диффа обязательно.** `git diff --stat`, потом глазами по ключевым
   файлам. Агент склонен тихо менять то, что не просили.
4. **DoD из `CLAUDE.md` прогоняется до коммита**, а не после.
5. **Если агент застрял** — не проси «попробуй ещё раз». Открывай новую
   сессию, давай суженный промт на конкретный сломанный кусок с текстом ошибки.
6. **Не давай следующую фазу, пока текущая не зелёная.**

## Полезные подкоманды в сессии

```
/clear                    сбросить контекст между подзадачами внутри фазы
Прочитай CLAUDE.md и docs/ARCHITECTURE.md перед началом.
Покажи план. Не пиши код, пока я не скажу «go».
Прогони ruff, mypy и pytest, покажи вывод.
```
